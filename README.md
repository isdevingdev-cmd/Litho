# Litho

Launch site for $LITHO.

A small marble statue woke up in the Elysian Fields. Tap, drag or flick his head to crack it with light.

## Files

- `index.html`: the whole site (HTML, CSS and JavaScript in one file)
- `assets/`: Litho's head, the stele and the gallery images
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Put it online with GitHub Pages

1. Push this folder to a GitHub repository (the files must be at the root of the repo).
2. In the repository: Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/` after a minute.
